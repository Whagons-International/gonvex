# Gonvex

Gonvex is a self-hostable realtime backend for TypeScript applications. It
combines transactional Reducers, exact SQLite change feeds, a persistent
normalized Local Replica, bounded Replica Collections, and indexed Live Queries.

```bash
npm create gonvex@latest my-app -- --template vite-react
cd my-app
npm install
npm run dev
```

The app-local module layout is:

```txt
my-app/
  gonvex/
    index.ts
    tasks.ts
    _generated/
  migrations/
    0001_initial.sql
```

## What Gonvex provides

- **Three executable kinds**: read-only Queries, atomic Reducers, and
  external-work Actions.
- **Generated TypeScript bindings**: typed function references and React hooks.
- **Committed change feed**: exact SQLite transactions drive realtime delivery.
- **Local Replica**: one normalized authoritative/optimistic store for browser
  and mobile state.
- **Replica Collections**: bounded authorized entity sets persisted locally.
- **Live Queries**: exact server-computed windows for large datasets.
- **Centralized visibility**: one old/new row visibility decision for snapshots,
  Live Queries, Replica Collections, and revocation.
- **Control Plane and tenants**: global Accounts, tenant-local Members, routing,
  and isolated tenant databases.
- **Durable background work**: outbox Actions and persisted scheduling.

## Core concepts

```txt
Account
  Global authenticated human or service identity.

Member
  Account's tenant-local identity, roles, teams, and permissions.

Control Plane
  Runtime-owned identity, tenant directory, and database-routing database.

Tenant database
  Tenant-local Members and application data.

Query
  Read once; arbitrary SQL is allowed.

Replica Collection
  Keep a bounded structured entity set synchronized locally.

Live Query
  Keep an exact structured server window synchronized without replicating the
  entire dataset.
```
