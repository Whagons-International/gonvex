# Queries, Reducers, and Actions

Gonvex application code has exactly three executable kinds.

## Query

A Query is read-only. A one-shot Query and a Live Query both use a structured
plan, so Gonvex can inject the table's centralized visibility rule before SQL
executes. A Replica Collection is the bounded local delivery mode for the same
read model.

```ts
import { query, schema } from "@gonvex/module-sdk";

export const list = query({
  args: schema.object({ workspaceId: schema.id("workspaces") }),
  result: schema.array(schema.object({ id: schema.id("tasks"), title: schema.string() })),
  liveQueryPlan: {
    table: "tasks",
    key: "id",
    columns: ["id", "title"],
    where: { operator: "eq", column: "workspaceId", value: { argument: "workspaceId" } },
  },
});
```

## Reducer

Reducers are the only normal durable write path. Each invocation is one atomic
Postgres transaction: all database changes commit together or none commit.
Every interactive Reducer declares an optimistic transaction or an explicit
reviewed `nonOptimisticReason`.

```ts
import { reducer, schema } from "@gonvex/module-sdk";

export const rename = reducer({
  args: schema.object({ id: schema.id("tasks"), title: schema.string() }),
  result: schema.object({ id: schema.id("tasks"), title: schema.string() }),
  offline: { mode: "allowed", conflict: "expectedVersion" },
  optimistic: {
    effects: [{ operation: "patch", entity: "tasks", id: ["id"], fields: { title: { $arg: "title" } } }],
  },
  run: ({ db }, args) => db.update("tasks", args.id, { title: args.title }),
});
```

## Action

Actions perform external work such as HTTP, email, AI, files, or long-running
computation. They receive no capabilities by default and never receive an
application database handle. Declare exact network origins, secrets, and named
Query/Reducer tools. Reducers record external work in the durable outbox so it
runs after commit.

```ts
import { action, schema } from "@gonvex/module-sdk";

export const send = action({
  capabilities: {
    networkOrigins: ["https://example.test"],
    tools: { markNotified: { kind: "reducer", function: "tasks.markNotified" } },
  },
  args: schema.object({ taskId: schema.id("tasks") }),
  result: schema.object({ queued: schema.boolean() }),
  run: async ({ tools, fetch }, args) => {
    await fetch("https://example.test/notify", { method: "POST", body: JSON.stringify(args) });
    await tools.markNotified(args);
    return { queued: true };
  },
});
```

An agent-profile Action may declare `capabilities: { functions: true }` and
invoke an interactive Query, Reducer, or Action by its signed catalog path. The
Rust host checks the active artifact hash, schema, tenant Member, and function
classification before dispatch. The target still runs through its normal
visibility and authorization path. This capability does not expose SQL or
database credentials.

## Generated React surface

```tsx
useQuery(api.tasks.get, args)
useLiveQuery(api.tasks.grid, args)
useReplicaCollection(api.tasks.recent, args)
useReducer(api.tasks.rename)
useAction(api.mail.send)
```

The Local Replica is the only frontend source of server state. Do not copy
Gonvex data into React state, call manual refetches after Reducers, write the
Gonvex store directly, or own WebSocket/subscription lifecycle code.
