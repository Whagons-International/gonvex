# Installation

Gonvex application modules are TypeScript. Install the CLI, client, React
bindings, and module SDK through npm.

## New project

```bash
npm create gonvex@latest my-app -- --template vite-react
cd my-app
npm install
```

The starter includes `@gonvex/module-sdk`, `@gonvex/client`, `@gonvex/react`,
and `@gonvex/cli`.

## Existing project

```bash
npm install @gonvex/client @gonvex/react @gonvex/module-sdk
npm install --save-dev @gonvex/cli
npx gonvex init
```

Recommended scripts:

```json
{
  "scripts": {
    "dev": "gonvex dev -- vite",
    "gonvex:dev": "gonvex dev",
    "gonvex:once": "gonvex dev --once"
  }
}
```

## Project layout

```txt
gonvex/
  index.ts
  tasks.ts
  _generated/
migrations/
  0001_initial.sql
gonvex.json
.env.local
```

`gonvex dev` scans TypeScript modules, requires literal argument and result
schemas, builds a self-contained JavaScript artifact, applies versioned SQL
migrations, and writes generated bindings. Application development uses the
same TypeScript module workflow as the frontend.

## Runtime options

```txt
Local runtime       Runtime and Postgres run locally.
Self-hosted runtime You operate the runtime, Control Plane, tenant databases,
                    and optional object storage.
Hosted runtime      No generally available public Gonvex Cloud service yet.
```

## Environment variables

```txt
GONVEX_PROJECT_ID=prj_...
GONVEX_RUNTIME_URL=http://localhost:8080
GONVEX_PROJECT_KEY=gvx_...
VITE_GONVEX_PROJECT_ID=prj_...
VITE_GONVEX_URL=http://localhost:8080
VITE_GONVEX_WS_URL=ws://localhost:8080/ws
```

The runtime needs Control Plane configuration and tenant database connections.
Redis and Valkey are not used by the Rust runtime. Application code must not hardcode
tenant database URLs.

## Generated files

Generated files belong in `gonvex/_generated/`. Import them from the frontend
and do not edit them manually:

```ts
import { api } from "./gonvex/_generated/api";
```
