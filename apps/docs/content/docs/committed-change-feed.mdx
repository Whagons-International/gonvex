---
title: Committed Change Feed
description: Exact SQLite commits drive Replica and Live Query delivery.
---

Gonvex does not ask application code what a Reducer might write.

Every application table appends committed row changes to
`_gonvex_sync_changes`. After commit the runtime publishes an in-process
wake-up signal; Gonvex reads the durable transaction revision before routing it.

Live Query freshness is:

```text
computedRevision >= requiredRevision
```

If a newer revision arrives during execution, the older result cannot become
current. Retention timers have no correctness role. Unknown-dependency and
broad invalidation fallbacks do not exist.
