# v0.5.2-sqlite.1

SQLite storage prerelease on npm's `sqlite` dist-tag (`staging` and `latest`
unchanged). Release branch `perf/release-sqlite.1` `d18f04d9`: the perf
integration candidate `f23a2194` plus the export fixes from `deploy/sqlite-staging`.

- **Delivery v3** (`perf/delivery-v3`): batched replica frames (negotiated; older
  clients keep the per-transaction frames), replica-state without a per-client
  mirror, work moved off the network threads, direct SQLite without sqlx on the
  hot paths, visibility masks, smaller WebSocket buffers with per-socket caps and
  a blocked-send timeout (close 4008).
- **Action depth and scheduled load** (`perf/action-depth`): durable hops restart
  at depth 0 (`GONVEX_MAX_DURABLE_HOPS`, default 32); on-demand Action isolates
  released after 60 s idle; one top-level Action at a time on small hosts
  (`GONVEX_ACTION_CONCURRENCY`); one outbox drainer; per-tenant cron stagger and
  no-op cron commits. Fixes `ctx.actions.enqueue` as a Reducer's first DB call and
  cron-queued runAfter jobs carrying the `_gonvex_system` actor.
- **export-sqlite**: `--preflight`, per-database `--resume`, trigger-aware copy
  order, empty-table column relaxation, module manifests not copied, and actor
  rewrites for pending durable work (`actorRewrites`).
- SDK: batch frames, presence v2 and need-hashes resume.

Install with `pnpm add @gonvex/client@sqlite` (or pin `0.5.2-sqlite.1`).
