# Gonvex 0.5.1

## Summary

- TypeScript artifacts now retain an explicitly declared `interactive: false`.
- The Rust runtime accepts signed 0.5.0 artifacts that contain a function classification but omit the matching interactive flag.
- Public system Queries and Reducers remain callable by normal clients and unavailable to delegated agent invocation.

## Compatibility

Upgrade all seven Gonvex npm packages together. The WebSocket protocol and Local Replica contract are unchanged.

The Rust runtime resolves function classification in this order:

1. Use an explicit `interactive` boolean.
2. If that field is absent, infer it from `classification`.
3. Use the original function-kind default only when both fields are absent.

This preserves existing signed artifact hashes. It also fixes new deployments containing public system Queries or Reducers such as `advancedVoice.clearCheckpointCapability`.
