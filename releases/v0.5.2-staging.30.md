# Gonvex 0.5.2-staging.30

The Rust V8 isolate now supports the WebCrypto operations used by Whagons push
notifications, sealed integration secrets, TURN credentials and signed webhooks.
Keys stay in GC-owned native objects. AES-GCM preserves the existing sealed
secret representation. See the published runtime contract for supported formats.

Queries and Reducers use their invocation's `ctx.now` for Date and intent entropy
for Math.random. Actions retain wall time and secure entropy. Generated local
reducers use the same globals without changing the browser's Date or Math.

Public behavioral cases run inside the real isolate and against the SDK. The
staging release command publishes all eight SDK packages under npm's staging
tag from the exact green staging commit, without pushing any branch.
